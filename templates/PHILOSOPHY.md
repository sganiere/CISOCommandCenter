# CISO Philosophy — [Your Name]

## Document Purpose

This is the CISO's core belief system: the "why" underneath every decision. It is loaded at the start of every session and is used by `/assess`, `/advise`, and `/brief` as a set of **tests** — a proposal that conflicts with a belief here should be flagged, not quietly accepted.

Doctrine in `CISO_CONTEXT.md` holds the operational rules (risk appetite, non-negotiable controls). This file holds the reasoning behind them. Doctrine entries should reference belief IDs where they derive from one.

Edited two ways only:
1. `/belief <text>` — proposes an addition or a refinement of an existing belief; the CISO confirms before anything is written.
2. Direct edit by the CISO, at any time.

Keep this file short. New ideas should be folded into an existing belief where they fit, not appended as a new one. If a belief can't change a decision, it doesn't belong here.

Every belief is tagged by category — **Technical**, **Risk**, or **Leadership** — and carries a `[J]` tag by default (these are judgments, not facts).

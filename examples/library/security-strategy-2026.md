# Security Strategy 2026–2028 — Meridian Global Bank (example)

*Fictional example document.*

## Priorities, in order

1. Keep PCI-DSS and SWIFT CSP continuously compliant (G1) — non-negotiable.
2. Cut time to detect before adding new preventive controls (G2, G3).
3. Reduce vendor concentration on LedgerCore (G4), starting with an honest exit-cost assessment.
4. ISO 27001 recertification by Q1 2028 (G5), largely a by-product of 1–3.

## Sequencing assumptions

- Engineering capacity is the binding constraint through 2027; cloud migration and CSPM compete for the same people.
- New vendor dependencies in the payment path are deferred until the LedgerCore exit assessment completes.

## Funding assumptions

- Flat budget in 2027; new initiatives are funded by retiring or deferring existing ones.
